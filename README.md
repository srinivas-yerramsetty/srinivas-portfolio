# Srinivas Yerramsetty — Portfolio Website

A responsive personal portfolio with a pure white, blue-accent visual theme, built with plain HTML, CSS and JavaScript. No framework or build tools are required.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser.
3. For a local development server, open a terminal in this folder and run:
   `python3 -m http.server 8000`
4. Visit `http://localhost:8000`.

## Before publishing
- Replace the `SY / YOUR PHOTO` placeholder in `index.html` with your profile photo.
- Replace `YOUR_EMAIL@example.com` with your preferred public contact email.
- Add your real LinkedIn profile URL.
- Review all education, skill, project and teaching details for accuracy.
- Add screenshots and links for more projects if you want.

## Publish with GitHub Pages
1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload the contents of this project folder (not the outer ZIP).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. After deployment, your site will be available at `https://<your-github-username>.github.io`.

GitHub Pages hosts static websites. It does not run a Python, Django, or Spring Boot backend.
